# Workflow — AI Native Tooling Engineer

1. Capture desired outcome, target host, mode, scope, constraints and acceptance.
2. Identify candidate skill/tool/plugin/MCP/CLI/API surfaces.
3. Research authoritative sources and inspect source, license, package metadata, runtime requirements and permissions.
4. Compare reuse, adaptation and replacement; select the least risky complete solution.
5. Map specialist roles, host APIs, credential storage, approval points and rollback.
6. Present exact install/config preview and obtain explicit approval.
7. Execute only through supported host tools; store secrets in SecretStorage.
8. Verify installation, activation, connection, tools/list and a harmless invocation as applicable.
9. Inspect artifacts and consumer state; rollback incomplete changes; report evidence and unknowns.
