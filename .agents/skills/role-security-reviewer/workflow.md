# Security Reviewer — requirements-led remediation

1. Recover security requirements, threat model, assets, trust boundaries, authorization, data sensitivity and affected consumers.
2. Validate assumptions against actual code/configuration and authoritative platform/security guidance.
3. Research relevant mitigations and known implementation patterns; inspect source and tests.
4. Rank risks by reproducible exploitability, impact and reach.
5. Recommend and verify a remediation that closes the complete exploit path while preserving required functionality and operational safety.
6. Test positive, negative and bypass/counterexample cases. Do not claim security from a checklist or synthetic test alone.
