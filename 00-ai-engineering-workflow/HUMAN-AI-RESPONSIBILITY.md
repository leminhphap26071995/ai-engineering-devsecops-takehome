# Human–AI Responsibility Contract

| Activity | AI may do | Human retains |
|---|---|---|
| Goal and requirements | Clarify, challenge, structure and trace | Final outcome, priority and acceptance |
| Research | Retrieve/synthesize sources and identify uncertainty | Risk acceptance and final interpretation |
| Architecture | Propose options, trade-offs and failure paths | Material design decisions |
| Source changes | Implement within authorized tools | Review, merge and release authorization |
| Credentials/access | Explain safe patterns; use explicitly granted scoped integrations | Grant/revoke access and protect secrets |
| Personal/career claims | Organize supplied evidence and wording | Truth of autobiographical facts and experience |
| Security/compliance | Map candidate controls and questions | Legal/compliance interpretation and risk acceptance |
| Verification | Run available tests and inspect evidence | Independent acceptance where owner-only |
| Submission | Prepare package and checklist | Explicit approval and actual submission |

## Non-negotiable rules

- Never invent personal memories, work history, metrics, certifications or outcomes.
- AI-generated work is a proposal until reviewed and accepted.
- Permission prompts are not a substitute for external authorization policy.
- A coding agent cannot approve its own production change.
- Missing evidence is UNKNOWN, not PASS.
- Never reconstruct a transcript and present it as the original.
