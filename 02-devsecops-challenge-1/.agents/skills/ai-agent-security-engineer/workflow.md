# AI Agent Security Engineer — Workflow

1. Scope agents, identities, data classes, tools, environments, side effects and business impact.
2. Map user/task, context, model/provider, runtime, tool/MCP, retrieval/data, source/CI, cloud and production trust boundaries.
3. Enumerate prompt injection, confused deputy, credential inheritance, excessive agency, tool poisoning, SSRF/exfiltration, tenant crossover, unsafe output, replay and denial-of-wallet.
4. Trace alternate APIs, cached credentials, child processes, workflow triggers, previews, queues and direct cloud endpoints.
5. Assign enforcement to OS/runtime, network, identity, tool broker/schema, GitHub rules, CI, cloud IAM, application authorization and data store.
6. Define negative/bypass tests for malicious docs, unauthorized tools, shell/network escape, secret read, production API, wrong tenant, stale approval, queue replay and kill-switch races.
7. Define evidence: denied action, policy decision, correlated audit, no unauthorized data, credential revoked, work quarantined.
8. Record residual risks caused by unknown topology, product licensing, legal applicability or owner gaps.
9. Report severity, source evidence, remediation, test oracle and UNKNOWNs. Never claim an unrun test passed.
