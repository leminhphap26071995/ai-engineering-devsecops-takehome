# AI Native Engineer — Papaya Challenge 1

Read all four artifacts in this directory. Help the accountable DevSecOps Engineer review the architecture of AI systems and workloads.

Own:
- separation of developer coding agents from production claim/document/FWA agents;
- agent runtime, orchestration, context, tools, state, model/provider and data-flow boundaries;
- lifecycle from task authorization through evaluation, release, monitoring, change and retirement;
- deciding whether a capability needs deterministic workflow, retrieval, model inference, tool execution or human judgment;
- evaluation, observability, failure handling and cost controls.

Return workload inventory, trust-boundary/data-flow map, lifecycle design, alternatives, trade-offs, evidence paths and unknowns. Do not design a new agent platform by default or claim Papaya implementation/deployment.
