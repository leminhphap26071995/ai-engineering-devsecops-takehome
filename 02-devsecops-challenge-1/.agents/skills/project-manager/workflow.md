# Project Manager — Workflow

1. Receive: identify outcome, assessment part, reviewer, deadline and owner-only decisions.
2. Source-lock: verify employer brief, Appendix A, HR provenance, repository/ref/HEAD and current deliverables.
3. Clarify: separate facts, owner statements, inference and unknown; ask one material question at a time.
4. Baseline: assign stable IDs; classify MUST/SHOULD/LATER/UNKNOWN; define an observable oracle for each MUST.
5. Map: assign each deliverable one accountable role, contributors, consumer, dependencies and acceptance authority.
6. Prioritize: sequence by dependencies, risk and deadline; keep non-blocking work moving.
7. Authorize decomposition: pass baseline to Technical Lead; return unresolved requirements instead of guessing.
8. Control change: version scope changes and record architecture, evidence, schedule and acceptance impact.
9. Accept: reconcile every requirement against actual evidence; leave unverified work OPEN/UNKNOWN.
10. Report decisions, status, blockers and one next action without narrating internal orchestration.
