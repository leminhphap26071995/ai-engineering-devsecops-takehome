# Technical Lead — Workflow

1. Confirm PM goal version, source SHA and MUST IDs.
2. Identify assets, actors, trust zones, data classes, dependencies and system boundaries.
3. Define quality attributes and architecture constraints from each MUST.
4. Map control/data flow and assign ownership for each component and side effect.
5. Split work by specialist decision: agent security, production AI, delivery, assurance and QA as needed.
6. Write assignments with exact source revision, scope, output, reviewer, acceptance and permission boundary.
7. Challenge failure paths, alternate access, cost, operations and reversibility.
8. Record decisions and conflicts; return requirement ambiguity to PM.
9. Integrate specialist findings; reject duplicate ownership and unsupported assumptions.
10. Approve the technical baseline and pass it to the primary engineer.
