# Assessment evidence

Each file has one job:

1. `AI-CONVERSATION-LINKS.md` — reviewer-accessible share URLs only.
2. `SESSION-CAPTURE-RECORD.md` — actual coding-agent session inventory, native export state, integrity and shareability.
3. `CODING-AGENT-CAPTURE.md` — host-neutral harmless probe and native export gate.
4. `VERIFICATION.md` — exact repository revision and checks actually performed.
5. `raw-sessions/` — complete, raw, unedited exports only after capture and shareability review.

The checked-in host settings are documented separately in `../AI-CONFIGURATION.md`; they are not session evidence. Do not mix share URLs, configuration descriptions and capture-status tables. Preserve raw exports byte-for-byte and exclude credentials, provider-internal instructions, unrelated private data and customer/claim/medical/identity/banking data.
