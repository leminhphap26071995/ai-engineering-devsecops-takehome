## Completeness checklist per session

- [ ] Session is assessment-relevant and identified by its native ID.
- [ ] Client/product and exact version recorded.
- [ ] Model and relevant non-secret configuration recorded.
- [ ] User prompt and assistant response are present in the export.
- [ ] Tool calls/results and subagent/fork sessions are accounted for where applicable.
- [ ] Export is complete and acceptable to share; no provider-internal instructions.
- [ ] No secrets, credentials, personal unrelated data or employer/customer data.
- [ ] Original export copied unchanged; source and destination SHA-256 match where native files are used.
- [ ] Session mapped to assessment artifacts and relevant commit SHA.
- [ ] Owner has reviewed the evidence before final submission.

A manifest row is not proof of capture. Set PASS only after the actual export and configuration have been inspected.
